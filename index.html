Help 使用帮助 · How to upload CSV

You can use .csv or .xlsx files. The first row can be a header or real data. 文件可以是 .csv 或 .xlsx，第一行可以是标题行，也可以直接是数据。
Setup for a new class 新班级设置
  1. Enter your class name and the Week 1 date in the welcome window (or tap Major).
  2. Open the Students card: import the students CSV, then the photos (Excel). The student list belongs to the whole major, so every course uses it.
  3. Open the Courses card: import the courses CSV, or tap New course. The order of steps 2 and 3 does not matter.
  4. Open the Class day card, pick a date and start marking attendance.
The 3 cards 三个卡片
  • Class day 上课: pick a date, combine classes, quick marks and Export PDF.
  • Courses 课程: choose, create, edit, move or delete courses, import the course CSV, set Week 1.
  • Students 学生: import students and photos, edit, reorder, delete.
  • Tap a card title to open it. Only one card is open at a time. Backup, Restore and Help are always in the top bar.

  • Every student gets a permanent no. inside the app. It is shown only in Setup, never on the sheet or PDF. Attendance and photos are linked to this number, so you can change an ID at any time with Edit and nothing is lost.
  • The ID can be empty. Two students cannot have the same ID.
  • Importing again: a row whose ID matches a student updates that student. A row without an ID is matched by passport name. If nothing matches, a new student is added.
  • Rows without a passport name are skipped.
  • Order: use ▲ ▼, or type a serial # and a new position, then tap Move. Photos are matched by this order.
  • Deleting a student removes him or her from all courses.
  • A sheet page holds up to 18 students. With 19 or more students, the next page is added automatically.

3Photos 照片

Open Setup → Students → Import / photos → One-time photo import and choose an .xlsx file with the pictures placed in the cells. Photos are matched to students by row order, so import the students first and keep the same order as the student list. You can also tap the camera icon next to one student to add a single photo.

4Excel to CSV tips 从 Excel 保存 CSV

  • In Excel choose Save As → CSV UTF-8 (Comma delimited). This keeps Chinese characters correct.
  • Plain .xlsx files also work. Only the first sheet is read.
  • Long ID numbers: format the ID column as Text so Excel does not change them to 6.7E+11.
If Chinese text looks broken (乱码), re-save the file as CSV UTF-8 and try again.

5Backup & restore 备份与恢复

  • Backup (top bar) downloads one .json file of the current major. The file name starts with the Chinese major name.
  • Restore (top bar) reads that file on any phone or computer. It replaces the data of the major with the same name, or creates it. Older backup files are converted automatically.
  • Back up at least once a week. The line under the cards shows when you last did. Clearing browser data erases everything saved in the browser. Your data stays on your device and is never uploaded.

6Courses, marking & combining 课程 · 点名 · 合并

  • New course / Edit course: set the title and teacher, then for each meeting choose the day, class time and week range (every week, odd weeks, even weeks or custom). Add another day for a course that meets twice a week.
  • Custom weeks: in the week list choose Custom 自定义, then type the week numbers with commas, for example 1,3,5,8,12. Ranges also work: 1-4,9.
  • Write the course title as Chinese name, a space, then the English name. The app shows both in the course card and lists.
  • When you edit a course, sessions that stay in the new schedule keep their attendance. The form shows how many sessions are kept, added and removed.
  • Move session changes the date and time of one single class (for example a make-up class).
  • Click or tap a Check In / Check Out cell: √ Present · L Late · O Approved leave · X Absent. A late student (L) is also counted in the Present total.
  • Combine (Class day card) shows only classes of the same date as the selected class. Pick 2 to 4 of them to make one all-day sheet.
  • PDF exports an A4 PDF. File names: 课程名-第N周-日期-出勤名单.pdf for one course, 班级名-第N周_日期-出勤名单.pdf for an all-day sheet.

7Dark mode 深色模式

  • Tap the sun / moon / screen button in the top bar to switch between Auto (follows your device), Light and Dark. Your choice is saved. The printed sheet and the PDF always stay white.
